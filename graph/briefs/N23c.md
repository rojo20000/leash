## Interface (CONTRACTS.md C12 excerpt; it wins over anything else here)

**`GET /api/me`** gains `"leash": {"enabled": bool, "dashboard_url": "http://127.0.0.1:8501"}`. Gate on exactly
`me.leash && me.leash.enabled` (an older server without the key means off).

**`POST /api/leash/search`** body `{"q": "<text>"}`; **`POST /api/leash/open`** body `{"patient_id": "pt-0042",
"view": "scheduling" | "full"}`. 200 response (a decision):
```json
{"state":"allow"|"block"|"escalate","call_id":"<32 hex>","tool":"search_patients"|"read_record",
 "view":"scheduling"|"full"|null,"patient_id":"pt-0042"|null,
 "reasons":[{"code":"RESOURCE_NOT_ALLOWED","stage":"policy","detail":"resource 'Condition' not allowed"}],
 "result": null | {"patients":[Patient,...]} (search allow) | {"patient_id":"pt-0042","resources":{"Patient":[...],"Encounter":[...],"DocumentReference":[...]}} (open allow),
 "redactions":[{"path":"resources.Patient[0].address","kind":"FIELD","source":"policy"}],
 "queue_id":"q-0004"|null,
 "reasoner":{"explanation":"...","risk_level":"high","policy_rule_ids":["resources.allowed"],
             "recommended_action":"deny","served_by":"replay"}|null,
 "dashboard_url":"http://127.0.0.1:8501"}
```
A Patient looks like `{"resourceType":"Patient","id":"pt-0001","name":[{"given":["Ana"],"family":"Stubson"}],"telecom":[]}`.
Errors: 502 `{"state":"unavailable","call_id":"...","error":"Leash gateway unavailable: ... Nothing was shown from
Clinic Assistant's own records."}`; 400/403/404 `{"error": "..."}`. All arrive via `err.message`.

**C12.5 markup** (exact strings; the check looks for them):
- In `<nav id="tabs">`, right after the Patients button:
  `<button id="tab-btn-leash" data-tab="leash" data-perm="view_patients">Leash</button>`
- A new section next to the other tab sections: `<section id="tab-leash" class="tab page" hidden>` containing: a heading
  "Patients through Leash"; the note "Integrated mode. Records come from Leash's synthetic EHR through the Leash
  gateway. Leash enforces one role policy (scheduling_assistant) for every Clinic Assistant role, so a full-chart
  request is blocked by design."; `<form id="leash-search-form">` with `<input id="leash-q" type="search" ...>` and a
  submit button "Search through Leash"; `<p id="leash-error" class="error"></p>`; `<ul id="leash-results"></ul>`;
  `<div id="leash-result"></div>`.
- JS, right after the `data-perm` loop: `if (!(me.leash && me.leash.enabled)) $("tab-btn-leash").hidden = true;`

**C12.5 behaviour** (`app.js`):
- Search submit: clear `#leash-error`, POST `/api/leash/search` with `{q}`; on allow, fill `#leash-results` from
  `result.patients`: one `<li>` per patient with the name (`name[0].given.join(" ") + " " + name[0].family`, falling
  back to the id), the id, and two buttons "Scheduling view" (`view: "scheduling"`) and "Full chart (Leash will
  block)" (`view: "full"`) that POST `/api/leash/open`. On block/escalate, render that state in `#leash-result`.
- Every decision rendering in `#leash-result` starts with a line "Request id: <call_id>".
- **allow** (open): badge `tier green` "Allowed by Leash" + "Scheduling view" or "Full chart"; for each key in
  `result.resources` an `<h3>` "<Type> (<count>)" and a `<pre>` with `JSON.stringify(list, null, 2)`; then "Removed by
  Leash" with one `<li>` per redaction "`path` (`kind`, `source`)", or "Nothing removed" when empty.
- **block**: badge `tier red` "Blocked by Leash"; one `<li>` per reason "`code` (`stage`): `detail`"; if `reasoner`, a box
  headed "Leash's explanation (advisory: a reviewer makes the final call)" with the explanation, "Risk: <risk_level>",
  "Recommended: <recommended_action>", "Rules: <policy_rule_ids joined by ', '>", "Source: <served_by>".
- **escalate**: badge `tier amber` "Waiting for review in Leash"; "Queue id: <queue_id>"; "Approve or deny it in the
  Leash dashboard at " + an `<a>` with `href` and text = `dashboard_url`, `target="_blank"`, `rel="noopener"`; then
  reasons and the reasoner box as for block.
- **unavailable / any error**: `#leash-error` gets `err.message`; `#leash-result` is emptied.
