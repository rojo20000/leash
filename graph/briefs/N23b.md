## Interface (CONTRACTS.md C12 excerpt; it wins over anything else here)

**Scope.** Leash's prototype enforces one role policy, `scheduling_assistant`. Every Clinic Assistant role is sent
as that role; a per-role clinician policy is future work. Two gateway actions only, for users with `view_patients`.
Records come from Leash; no fallback to Clinic Assistant's own `patients.json`, ever.

**Client you import** (`app/leash_client.py`, by N23a):
```python
LEASH_ROLE = "scheduling_assistant"
SCHEDULING_TYPES = ["Patient", "Encounter", "DocumentReference"]
FULL_TYPES = ["Patient", "Condition", "MedicationRequest", "Encounter", "DocumentReference"]
class LeashError(Exception)   # str(e) is one of: "Refusing non-local Leash gateway", "unreachable (<ExcClass>)",
                              # "HTTP <status>", "bad response", "call_id mismatch"
def enabled(policy: dict) -> bool   # policy["leash"]["enabled"] is True or env CLINIC_LEASH == "1"
def tool_call(policy: dict, tool: str, args: dict, session_id: str, call_id: str) -> dict
    # POSTs {"session_id","role":LEASH_ROLE,"tool","args","call_id"} to gateway_url + "/v1/tool-call";
    # returns the decision dict, or raises LeashError. Does not check enabled().
```
Decision fields you read: `decision` (`allow|block|escalate`), `reasons` (list of `{"code","stage","detail"}`),
`result`, `redactions`, `queue_id`, `nemotron.reasoner` (may be null; `nemotron` may be absent).

**C12.4 App methods**:
```python
def leash_status(self) -> dict      # {"enabled": leash_client.enabled(self.policy),
                                    #  "dashboard_url": self.policy.get("leash", {}).get("dashboard_url", "http://127.0.0.1:8501")}
def leash_call(self, sess: dict, tool: str, args: dict, view: str | None = None,
               patient_id: str | None = None) -> tuple[int, dict]
```
`leash_call`: `call_id = uuid.uuid4().hex`; `session_id = "clinic-assistant:" + sess["user"]`; call
`leash_client.tool_call(self.policy, tool, args, session_id, call_id)`; return `(200, body)` or, on `LeashError e`,
`(502, {"state":"unavailable","call_id":call_id,"error":f"Leash gateway unavailable: {e}. Nothing was shown from Clinic Assistant's own records."})`.
200 body:
```json
{"state":"allow","call_id":"<32 hex>","tool":"read_record","view":"scheduling","patient_id":"pt-0042",
 "reasons":[{"code":"OK","stage":"policy","detail":""}],
 "result":{"patient_id":"pt-0042","resources":{...}},"redactions":[...],
 "queue_id":null,"reasoner":null,"dashboard_url":"http://127.0.0.1:8501"}
```
`state` = `decision`; `view`/`patient_id` null for search; `result` = decision `result` if allow else null;
`redactions` = decision's (default `[]`); `queue_id` = decision's (default null); `reasoner` = the dict of
`explanation`, `risk_level`, `policy_rule_ids`, `recommended_action`, `served_by` from `nemotron.reasoner`, or null.

**C12.6 Audit**: exactly one entry per `leash_call`, either outcome:
`self.audit.write("leash_tool_call", sess["user"], call_id=call_id, tool=tool, view=view, patient_id=patient_id,
decision=<"allow"|"block"|"escalate"|"unavailable">, reasons=[r["code"] for r in reasons], queue_id=...,
role_sent=leash_client.LEASH_ROLE, session_id=session_id, results=<len(result["patients"]) for a search allow, else
None>, error=<str(e) for unavailable, else "">)`. Never the search text, record contents, redactions or explanation.

**Routes** (checks in this order; each failure returns before any gateway call or audit entry):
| Route | Body | Checks | Then |
|---|---|---|---|
| `POST /api/leash/search` | `{"q": "smith"}` | session (401), `view_patients` (403 `{"error":"Your role cannot open patient records."}`), `enabled` (404 `{"error":"Integrated mode is off."}`), `q = str(data.get("q","")).strip()` 1..80 chars (400) | `leash_call(s, "search_patients", {"name": q})` |
| `POST /api/leash/open` | `{"patient_id":"pt-0042","view":"scheduling"}` | the same first three; `patient_id` matches `^pt-\d{4}$` (400); `view` in `scheduling`/`full` (400) | `leash_call(s, "read_record", {"patient_id": pid, "resource_types": SCHEDULING_TYPES or FULL_TYPES}, view, pid)` |
`GET /api/me` gains `"leash": app.leash_status()` (always present). (Same-origin is already checked at the top of `do_POST`.)
