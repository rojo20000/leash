## Interface (CONTRACTS.md C12 excerpt; it wins over anything else here)

**Scope.** Leash's prototype enforces one role policy, `scheduling_assistant` (resources Patient, Encounter,
DocumentReference). Every Clinic Assistant role is sent as `"role": "scheduling_assistant"`; a per-role clinician
policy is future work. A full-chart request (all five types) is blocked by Leash by design.

**C12.2 Switch** (`config/policy.json`):
```json
"leash": {"_comment": "Integrated mode: patient search/open go through the Leash gateway. Off by default.",
  "enabled": false, "gateway_url": "http://127.0.0.1:8000", "timeout_seconds": 10,
  "dashboard_url": "http://127.0.0.1:8501"}
```
plus `_enabled` (say `CLINIC_LEASH=1` turns it on for one run without editing this file), `_gateway_url` (must be a
loopback address; anything else is refused), `_timeout_seconds`, `_dashboard_url` (where Leash's approval queue is).

**C12.3 Client** (`app/leash_client.py`):
```python
LEASH_ROLE = "scheduling_assistant"          # the only policy Leash has
SCHEDULING_TYPES = ["Patient", "Encounter", "DocumentReference"]
FULL_TYPES = ["Patient", "Condition", "MedicationRequest", "Encounter", "DocumentReference"]
class LeashError(Exception): ...            # message is short and has no record contents
def enabled(policy: dict) -> bool
def tool_call(policy: dict, tool: str, args: dict, session_id: str, call_id: str) -> dict   # the C5.2 decision
```
- `enabled(policy)` = `policy.get("leash", {}).get("enabled") is True or os.environ.get("CLINIC_LEASH") == "1"`.
- `tool_call` reads only `policy["leash"]["gateway_url"]` and `policy["leash"].get("timeout_seconds", 10)`; it does
  not check `enabled`. URL = `gateway_url.rstrip("/") + "/v1/tool-call"`. First `llm._assert_local(url)`; on
  `RuntimeError` raise `LeashError("Refusing non-local Leash gateway")` before any socket is opened.
- Opener = `urllib.request.build_opener(urllib.request.ProxyHandler({}), NoRedirect())`, where
  `class NoRedirect(urllib.request.HTTPRedirectHandler)` returns `None` from `redirect_request` (a redirect then
  surfaces as an HTTPError, i.e. `"HTTP <status>"`).
- `POST` JSON body exactly `{"session_id": session_id, "role": LEASH_ROLE, "tool": tool, "args": args,
  "call_id": call_id}`, header `Content-Type: application/json`, the timeout above.
- `LeashError` messages are exactly one of: `"Refusing non-local Leash gateway"`; `"unreachable (<exception class
  name>)"` for `URLError`/`OSError`/timeout; `"HTTP <status>"` for any status other than 200; `"bad response"` for a
  body that is not a JSON object or a `decision` not in `allow|block|escalate`; `"call_id mismatch"` when the
  returned `call_id` differs from the one sent. Otherwise return the parsed decision dict unchanged.

**C12.7 Stub gateway** (`tests/stub_gateway.py`; standard library only; imports nothing from `app`):
```python
class StubGateway:
    def __init__(self, mode: str = "allow"): ...  # starts ThreadingHTTPServer(("127.0.0.1", 0)) in a daemon thread
    url: str             # "http://127.0.0.1:<ephemeral port>"
    mode: str            # set any time: "allow" | "block" | "escalate" | "http500" | "wrong_call_id" | "not_json"
    requests: list[dict] # every parsed POST /v1/tool-call body, in arrival order
    def stop(self) -> None   # shutdown() + server_close(); idempotent; afterwards url refuses connections
```
Usage: `gw = StubGateway(); self.addCleanup(gw.stop)`; then `gw.mode = "block"`. Silence `log_message`. Answer only
`POST /v1/tool-call` (anything else 404). Every decision echoes the request's `call_id`, `session_id` and `tool`;
`wrong_call_id` returns `"call_id": "0" * 32` (otherwise allow); `http500` returns status 500
`{"detail":"stub error"}`; `not_json` returns status 200 with body `not json`. Every decision also has `"seq": 1`,
`"scores": {"injection": null, "anomaly": null}`, `"latency_ms": {"policy": 0.01, "total": 0.1}`, `"audit_hash":
"stub"`, `"ts": "2026-11-21T16:30:00.000000Z"`, `"core": "stub"`, `"ml": "stub"`. Canned bodies:
- `allow`, tool `search_patients`: `"decision": "allow"`, `"reasons": [{"code":"OK","stage":"policy","detail":""}]`,
  `"result": {"patients": [{"resourceType":"Patient","id":"pt-0001","name":[{"given":["Ana"],"family":"Stubson"}],
  "telecom":[]}, {"resourceType":"Patient","id":"pt-0002","name":[{"given":["Ben"],"family":"Stubson"}],
  "telecom":[]}]}`, `"redactions": []`, `"queue_id": null`, `"nemotron": {"mode":"replay","jailbreak":null,
  "nemoguard":null,"content_safety":null,"reasoner":null}`.
- `allow`, tool `read_record`: as above but `"result": {"patient_id": <args.patient_id>, "resources": {t: [] for t in
  args.resource_types}}`, with `resources["Patient"] = [{"resourceType":"Patient","id":<pid>,"name":[{"given":
  ["Ana"],"family":"Stubson"}],"telecom":[]}]` when Patient is requested, and `"redactions": [{"path":
  "resources.Patient[0].address","kind":"FIELD","source":"policy"}]`.
- `block`: `"decision": "block"`, `"reasons": [{"code":"RESOURCE_NOT_ALLOWED","stage":"policy","detail":"resource
  'Condition' not allowed"}]`, `"result": null`, `"redactions": []`, `"queue_id": null`, `nemotron.reasoner` =
  `{"served_by":"fallback:template","model":"","latency_ms":0.1,"risk_level":"high","explanation":"STUB-EXPLANATION
  Leash blocked this call.","policy_rule_ids":["resources.allowed"],"recommended_action":"deny","advisory":true,"error":""}`.
- `escalate`: `"decision": "escalate"`, `"reasons": [{"code":"RECORD_RATE_EXCEEDED","stage":"policy","detail":"11
  distinct records in window, max 10"}]`, `"result": {"status":"pending_approval","queue_id":"q-0004"}`,
  `"queue_id": "q-0004"`, reasoner as block but `"risk_level":"medium"`, `"recommended_action":"needs_more_info"`,
  `"policy_rule_ids":["rate.max_records"]`.

## Tests (`tests/test_leash_client.py`; no `App`, no `app.server` import)
